# Ideation Expansion Method

Use this method after a verified audience insight and initial strategic framing exist, when the goal is to generate enough distinct creative directions for a useful test plan without turning quantity into random variation.

Classify this as a methodology under [`KNOWLEDGE-TAXONOMY.md`](../_shared/KNOWLEDGE-TAXONOMY.md). It expands hypotheses; it does not manufacture evidence or prove that any idea will perform.

## Expansion sequence

Start with one verified insight or clearly labeled hypothesis, then expand deliberately:

```text
1 verified insight
→ 2–5 evidence-compatible angles
→ 1–2 mechanics per selected angle
→ 1–2 concepts per mechanic
→ controlled hook variants
→ 1–2 suitable visual formats
→ proof treatment
→ CTA
→ controlled test cells
```

The counts are planning ranges, not quotas. Generate fewer when the evidence supports fewer meaningful directions.

## What changes at each layer

- **Angle:** Change the strategic reason to care.
- **Mechanic:** Change how the concept makes the audience understand, feel, compare, observe, or infer the angle.
- **Concept:** Change the specific scene, narrative, demonstration, or central idea built around the mechanic.
- **Hook:** Change the opening expression while preserving the underlying angle and intended mechanic.
- **Visual format:** Change the production vessel only when it suits the concept, placement, and proof requirement.
- **Proof:** Change the evidence treatment only when multiple substantiated forms exist.
- **Offer framing / CTA:** Change these only when the test question is specifically about the offer or next action.

Do not count cosmetic rewrites, crop adaptations, background changes, synonym swaps, or different labels for the same mechanic as new strategic ideas.

## Expansion gates

Before expanding an idea, confirm:

1. The source insight is observed, supplied, or explicitly labeled as a hypothesis.
2. The angle is supported by product truth and does not require an invented claim.
3. The selected mechanic has a clear communication job and does not imply unsupported proof.
4. The concept expresses the angle through the mechanic rather than adding unrelated novelty.
5. The hook matches the best-supported awareness/belief state and does not overstate proof.
6. The visual format is appropriate for the mechanic, concept, product, placement, and production constraints.
7. The test cell can be interpreted because the major variable is identifiable.

If a gate fails, do not compensate by producing more variants.

## Diversity test

Two ideas are strategically distinct only if a reasonable reviewer can explain what different proposition, belief shift, motivation, objection, mechanic, or proof job each one is testing.

Ask:

- Would these ideas teach different things if one wins and the other loses?
- Is the reason to care different, or only the wording?
- Does the audience reach the point through a different mechanic, or only a different visual treatment?
- Is the proof doing a different strategic job, or only appearing in a different layout?
- Does the audience need a different belief to accept each idea?

If the answer is no, consolidate them.

## Ranking

Prioritize cells using evidence fit, business relevance, differentiation, proof availability, production feasibility, and learning value. Do not rank an idea as likely to win simply because it sounds clever, uses a fashionable mechanic, or follows a known framework.

## Handoff to testing

The expansion output becomes an input to [`workflows/creative-ideation-engine.md`](../_shared/workflows/creative-ideation-engine.md) and then [`workflows/creative-testing.md`](../_shared/workflows/creative-testing.md). Before launch, each selected cell needs a success signal, business guardrail, decision window, and controlled variable.

## Anti-patterns

Reject:

- idea quotas that force weak angles, mechanics, hooks, or formats
- one insight rewritten many ways and labeled many concepts
- format swapping presented as strategic learning when the underlying concept and mechanic are unchanged
- fabricated testimonials, statistics, urgency, scarcity, competitor claims, or product mechanisms
- combining new angle + new mechanic + new hook + new format + new offer in one learning cell without a deliberate multivariate design
- treating generated ideas as customer evidence
- calling an untested angle, mechanic, hook pattern, or format a winner, best practice, or proven pattern

The purpose of expansion is not maximum output. It is maximum useful learning per production round.
