# Structure Selection

Matches a copywriting structure to the communication goal rather than defaulting to one. Each structure organizes an argument differently; picking the wrong one for the goal produces copy that reads correctly but persuades the wrong way.

## Structures

| Structure | Sequence | Fits |
|---|---|---|
| AIDA | Attention → Interest → Desire → Action | Cold or low-awareness audience needing to be introduced to the problem and offer in one piece |
| PAS | Problem → Agitate → Solution | Audience that already recognizes the problem but hasn't connected it to urgency or a solution |
| FAB | Feature → Advantage → Benefit | Audience evaluating a specific capability against alternatives, where the mechanism itself is part of the decision |
| UGC narrative | Hook → Problem → Lived experience → Proof → CTA | A testimonial-style piece narrated in a genuine customer or creator's voice; fits native-feeling formats where `$tiktok-ads` or `$influencer-marketing` content is the delivery vehicle |
| BAB | Before → After → Bridge | Audience motivated by contrast — showing the gap between current and desired state, with the offer as the bridge |
| Rule of One | One audience, one problem, one promise, one action | Applies underneath every structure above, not as an alternative to them |

## Method

1. Identify the audience's awareness level — unaware, problem-aware, solution-aware, product-aware, most-aware — from `$icp-jtbd` or `$customer-research` evidence where available.
2. Match structure to awareness: AIDA for low awareness needing full introduction; PAS for problem-aware audiences; FAB for solution- or product-aware audiences comparing specifics; BAB where the contrast itself is the most persuasive element. UGC narrative fits a native or creator-voiced format regardless of awareness stage, since its persuasive force comes from perceived authenticity rather than argument structure alone — confirm the underlying experience is genuine before drafting in this voice.
3. For a sequence rather than a single piece, structures can compose across pieces — an early email in PAS, a later one in FAB as the audience becomes more solution-aware — but each individual piece should still follow the Rule of One.
4. Do not force a structure that doesn't fit the claim; a piece with no genuine before/after contrast forced into BAB reads as invented rather than true.

## Rules

- Awareness level, not preference, selects the structure. Do not default to one structure across every piece regardless of audience state.
- A structure organizes an argument; it does not manufacture evidence for it. If the "Desire" or "Agitate" stage requires a claim the evidence doesn't support, the structure is not license to write it anyway.
- For a multi-piece sequence, track which awareness stage each piece assumes so the sequence doesn't repeat the same introduction or skip a stage the audience hasn't reached.
- A UGC narrative structure is written in a real or credibly representative customer/creator voice; do not fabricate a customer experience or present a written piece as a genuine testimonial when it is not, per this skill's existing prohibition on fabricated customer language.
- Some sources order the feature/benefit/advantage sequence differently (Feature → Benefit → Advantage rather than Feature → Advantage → Benefit above); no authoritative source settles which ordering is correct, and the practical difference is small. This reference keeps FAB as documented, and either ordering is acceptable so long as the piece is internally consistent and matches the audience's actual decision process.
